# 07_IT2仕様書・結果 — 結合テスト2（外部結合）

> **平たく言うと**：作った道具を「外から使う側」の立場で確かめる。コマンドライン経由と、MCP（エージェントが道具を使うための共通方式）経由の両方で質問→検索→出典つきの結果が返ることと、おかしな使い方をしたときに決めた通りの終わり方（終了コードとメッセージ）になることを見た。

- バージョン：v1.0（2026-11-26、実施完了）
- 前提： MCPサーバーはこの工程の直前に製造した（内部設計の方針どおり）。検索の仕組みは持たず、検索部品をそのまま呼ぶ作りにした

## 確認項目と結果

| 項目 | 期待 | 結果 |
|---|---|---|
| MCP経由で道具が見える | search_knowledge が1件見える | 一致 |
| MCP経由の検索（答えがある質問） | 候補あり＝true、最上位に出典（文書名・見出し・位置）が付く | 「パスワード管理方針／共有の禁止／位置2」で一致 |
| MCP経由の検索（答えがない質問） | 候補あり＝false | 「明日の天気」で false、一致 |
| CLI：索引がない状態で検索 | 終了コード3＋「先に取り込みが必要」のメッセージ | 一致 |
| CLI：設定ファイルがない | 終了コード2＋設定の誤りのメッセージ | 一致 |
| CLI：設定の項目名が違う | 終了コード2＋不足項目を名指しするメッセージ | 一致（想定外だったが正しく働いた） |
| CLI：評価ファイルの形式が壊れている | 終了コード4＋行番号つきの理由 | 一致 |

## 実施中に出た問題と、直した内容

- MCPの公式部品が新版（2.x）で名前と置き場所が変わっていた（FastMCP→MCPServer）。製造時に気づいて新版の方式に合わせた。バージョンを固定せずに入れると、こういう互換性の崩れが起きることの実例として残す

## 残件

- 実データでの利用確認は総合結合（IT3）で行う（この工程はサンプル索引での外部結合まで）
