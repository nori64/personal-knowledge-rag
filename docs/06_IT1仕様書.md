# 06_IT1仕様書 — 結合テスト1（内部結合）

> **平たく言うと**：部品をつないで、本物の意味検索モデルで「取り込み→検索→評価」が最後まで通るかを見る。数字はこの後のモデル選定（総合結合）の土台になる速報値で、確定値ではない。

- バージョン：v1.0（2026-11-26、実施完了）
- 対象：サンプル文書16件、サンプル質問セット33件、埋め込みモデルは multilingual-e5-small（設定どおり）

## 確認項目

| 項目 | 期待 |
|---|---|
| 取り込みが完了する | 警告なしで索引ができる（文書数・チャンク数がサンプルと一致） |
| 検索が返る | 質問に対して出典（文書名・見出し・位置）つきで返る |
| 評価が3方式とも実行できる | キーワードのみ／ベクトルのみ／組み合わせ、で集計が出る |
| 終了コード | 正常時は0。索引なしでは3になる |

## 結果（2026-11-26、サンプル質問セット33件）

| 項目 | 結果 |
|---|---|
| 取り込み | 16文書・40チャンク、警告なし、終了コード0 |
| 検索 | 出典（文書名・見出し・位置）つきで返ることを確認 |
| 評価（キーワードのみ） | Recall@5 96.3%、出典の正確率100%、答えなし検出率83.3% |
| 評価（ベクトルのみ） | Recall@5 100%、出典の正確率100%、答えなし検出率66.7% |
| 評価（組み合わせ） | Recall@5 100%、出典の正確率100%、答えなし検出率83.3%、誤判定率16.7% |

## 実施中に出た問題と、直した内容

1. **候補あり判定が構造的に壊れていた**： 統合スコアの正規化では「何か返れば常に関連度が高く」なり、ベクトルと組み合わせで答えなし検出率が0%だった。実測で分布を見たうえで、判定を生の証拠（最上位のコサイン類似度0.85以上、かつキーワードでも当たること）に変えた。直後は上の表のとおり（組み合わせで検出率0%→83.3%）。内部設計へ差し戻しとして記録した
2. **順位の同点処理が実行ごとに揺れていた**： キーワード評価のRecallが同じ条件で96.3%と92.6%に揺れた。同点時はチャンク番号で安定させるよう直し、再現する数字になった

## 残件（総合結合へ）

- コサイン類似度の閾値0.85は、サンプル33件の分布から決めた暫定値。実データと質問数を増やして決め直す
- 埋め込みモデルの最終選定（候補3件の比較）は総合結合で行う
