# 03_評価設計 — 個人用ナレッジRAG

- バージョン：v0.1

## 1. 評価セットの作り方
- 本人が実際に聞きそうな質問を30〜50件作る（作り方は、過去に自分がネロへ聞いた質問を振り返るのが最も本物に近い）
- 各質問に「答えがあるべき文書と見出し」を付け、うち最低5件は「文書に答えがない質問」にする
- 評価セットのうち、公開リポジトリにはサンプルドキュメント用のものだけを置く。実文書用の評価セットは公開しない

## 2. 指標
| 指標 | 定義 |
|---|---|
| Recall@5 | 期待するチャンクが検索上位5件に入った質問の割合 |
| 出典正確率 | 返した出典（文書名・見出し）が実在し、質問に対応していた割合 |
| 答えなし検出率 | 答えがない質問で、根拠候補なしと正しく返せた割合 |

## 3. 比較の作法
- ベースラインはキーワード検索のみ
- 変更（ベクトルのみ／ハイブリッド／チャンクサイズ変更／埋め込みモデル変更）ごとに同じ評価セットで測り直し、前後の表を残す
- 結果は良し悪しに関わらず記録する。モデル選定はこの表で決める
