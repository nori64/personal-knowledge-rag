# RAG 結合テスト2（IT2）スキル

## 目的

- 外部結合を確認する。CLI／MCPインターフェース越しに、接続相手（ネロ）が検索を使い、出典付きで回答できることを検証する。

## 入力

- IT1完了済みコード、外部設計書のIF仕様

## 成果物

- IT2仕様書・結果報告書（docs/07_IT2仕様書・結果.md）：接続シナリオ、実機での応答記録、異常系の結果

## 手順

- 1. 接続シナリオを書く：ネロが質問を受け、ragcliを呼び、出典付きチャンクを得て回答する一連の流れ
- 2. 実機（本人のPC）で疎通させる。VM側だけで完結させず、実際の接続経路で確認する
- 3. 異常系を確認する：PCオフライン、DB未作成、ヒットなし、のときにエージェント側がどう振る舞うか
- 4. IF仕様（JSON形式、終了コード）と実物が一致しているか照合する
- 5. MCP化する場合は、同じシナリオをMCPツール呼び出しでも再実施する

## ゲート（完了条件）

- 実機でネロ経由の質問→検索→出典付き回答が成功し、記録が残っていること

## 失敗しやすい点

- ローカル実行だけで接続確認したことにする／異常系でエージェントが根拠なく回答してしまう

## 次工程への引き継ぎ

- 成果物の場所と、未決事項・差し戻し事項を明記して次工程Agentへ渡すこと。口頭だけの引き継ぎはしない

## 工程記録

- 工程の開始と終了時に、process/templates/phase-record-template.md の形式で工程記録を書き、process/phases/ に残すこと。ゲートは工程記録が書かれていることも条件とする

## 自己レビュー

- ゲート前に共通スキル「自己レビュー」（skills/common-self-review）で成果物を確認し、レビュー記録を process/reviews/ に残すこと。自己レビューが済むまでゲート判定に進まない
