# 全工程にスキル（標準手順）とAgent（役割定義）を作成する

- 日付： 2026-11-26
- 状態： 採用
- 関係する工程： 全工程

## 背景
工程を踏むだけでは「今回はそう進めた」で終わる。手順を標準化し、
別のAgentでも再現できる形にして初めて、仕組みとして残る。

## 決定
- 各工程にスキル（標準手順）1件とAgent（役割定義）1件を作る
- 進行管理Agentを1件置き、状態とゲートを管理させる
- 雛形としてスキル9件・Agent10件を先行作成した（v0.1）

## 理由
- 標準化とエージェント化は自分の業務でも進めている方向であり、一貫性が示せる

## 影響
- 次の決定「スキルとAgentの設計を先行させる」により、この雛形は「設計前の先行作成」として位置づけ直された
